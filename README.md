# Invitación Digital Template

Template base para invitaciones digitales HTML, CSS y JavaScript.

## Estructura

css/

- variables.css → colores, fuentes, gradientes
- layout.css → estructura general
- components.css → elementos reutilizables
- responsive.css → adaptación móvil y escritorio
- style.css → diseño específico del modelo

js/

- script.js → funciones generales
- countdown.js → contador

assets/

- images → imágenes
- icons → iconos
- audio → música

## Reglas

- No usar estilos inline.
- Todo color debe salir de variables.css.
- Diseño Mobile First.
- Elementos únicos van en style.css.
- Componentes generales van en components.css.
